# 啄知 AI Flutter 客户端（Android / Windows）

Android 运行、后端连接和演示流程见 [Android 本地运行与功能演示](../docs/03_Android本地运行与功能演示.md)。

客户端使用 `API_BASE` 指定后端地址，默认 `http://10.0.2.2:8000` 适用于标准 Android 模拟器。USB 真机可结合 `adb reverse` 访问开发电脑的回环服务；登录界面也支持设置服务地址。

最终可用范围、测试证据及设备限制见 [本地测试报告](../docs/04_本地测试报告.md)。


首次无服务器会话时可直接进入本地体验，无需注册或运行自建后端。课程、资料、试卷、专注和夜鹭成长保存在手机上。用户在 AI 模型设置中填写兼容 Chat Completions 的服务地址、模型和 API Key，App 直接调用该服务；选中资料并主动生成后才会发送所选资料前 12000 个 Unicode 字符。

本地 AI 出题、资料格式、测试证据和限制见 [2026-11-10 本地 AI 组卷验收](../docs/10_2026-11-10_本地AI组卷验收.md)。服务器模式的 API_BASE 仅用于可选的既有后端功能。

Windows 桌面项目位于 `windows/`；运行与打包见 [桌面版开发与验收](../docs/12_Windows桌面版开发与验收.md)。PC 与 Android 的学习记录各自本地保存，尚无自动跨设备同步。
