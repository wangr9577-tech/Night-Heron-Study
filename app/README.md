# 啄知 AI Flutter 应用

应用通过 `API_BASE` 编译参数连接后端。Android 模拟器默认值为 `http://10.0.2.2:8000`；真机需与服务器处于可达网络，并配置服务器的局域网 IP，例如：

```powershell
flutter run -d <device-id> --dart-define=API_BASE=http://192.168.1.10:8000
```

Web 本机预览需显式设置 `--dart-define=API_BASE=http://127.0.0.1:8000`；服务端需要允许对应的浏览器跨域来源。开发 HTTP 会启用 Android 明文流量；正式部署应改用 HTTPS 并关闭明文。

当前实现覆盖登录注册、课程选择/创建、今日任务与调整、推荐、完成记录、月历、讲解任务创建、资料/讲解/图谱/问答/错题/复习入口、随堂练习、伙伴聊天、积分兑换投喂、文字口语及通知。学习资料、图谱、课程、问答和随堂练习使用乙侧演示桩，并在页面标明演示数据；演示作答不更新掌握状态、任务或奖励。真实乙侧学习服务尚待接入，接口缺失会显示加载错误。

伴学和口语目前是固定演示回复，不代表真实 AI 或语法评估；讲解以文本呈现，暂无真实语音。试卷导入、蓝图编辑、生成和提交页面以及资料/错题上传入口已实现，但当前乙侧演示桩不提供相应服务，无法完成端到端处理；真实联调尚未验证。录音与语音播放、部分任务类型跳转、完整日历编辑尚待开发。Android 工程已生成，构建 APK 需要安装并配置 Android SDK。
