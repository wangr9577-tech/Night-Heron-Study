# 数据契约变更记录

## 1.1.0 / 2026-11-08

- 新增 `PATCH /courses/{course_id}/knowledge/edges/{edge_id}`，可原子修改关系端点和类型，保持边 ID；重复、环和非法所属关系均拒绝，失败不改变旧边。
- 新增 `GET /courses/{course_id}/mistakes/{id}/review-original`，仅向具备课程内容审核权限且非记录本人的审核者提供上传原件。
- 课程审核和主观判分显式禁止自审；本地集成版本的授权由可信管理员按课程授予和撤销，普通注册及课程创建不产生审核权限。
- 教学课程新增 `generation_warnings` 列表。来源不足以生成随堂题时，保留可展示的课程内容并返回对应知识点的警告；缺少可讲解内容仍报错。旧课程缺省为空列表。
- **行为变化：**当前用户通过出题接口自建的题目只可自测，作答 `evidence_weight` 为 0、`evidence_exclusion_reason` 为 `self_authored_question`，不改变掌握状态，也不能完成任务或发放积分。独立审核者确认学生错题而生成的题目不受此限制。新规则仅作用于之后的判定，不回写历史记录。
- 有权限的用户查看自己题目的 answer-key 会记录答案暴露；冷却期内再作答不视作独立证据。

## 1.0.1 / 2026-11-03

- 新增 `PATCH /mistakes/{id}/transcription` 供学生校对识别文本，保留原始题面与作答。
- 新增 B6/B7 审核队列；审核操作支持独立教师身份，保留 confirmed_by/reviewed_by，结果归属学生。
- 题目提示的来源只含定位字段；通过 `POST /questions/{id}/sources` 显式展开全文并记录答案暴露。
- 同题辅助记录跨会话生效；24 小时内重复作答新增 recent_repeat 标记，掌握证据权重为 0。
- 上传按文件内容复用解析结果；同一出卷请求的幂等性不受后续蓝图编辑影响。
- 混合扫描页新增 pdf_text_ocr 解析方法；问答调用模型期间不持有数据库写事务。
- 共享结构继续兼容原有作答、课程、快照与事件字段，不更改甲方任务或积分接口。

## 1.0.0 / 2026-11-02

- 建立课程上下文、来源、后台任务、教学页面、作答结果、推荐项目、学习成果、快照的共享定义。
- 保留分工方案字段，额外明确对象 `id` 与 lesson_id/attempt_id 的等价关系。
- 采用 queued/running/succeeded/failed；result_ref 为 type/id 对象。
- 新增 practice_session_id 绑定服务端提示记录，防止提交时抹去提示历史。
- source_task_id 只关联甲方任务，不由乙方宣告整个任务完成。
- 推荐项目 type/target_id 供甲方路由；不传前端组件名或任意 URL。
- 题目答案、参考解析和验证参数不包含在学习者题面接口。
- 事件游标只增且强制用户范围，甲方按 event_id 去重消费。
- 初始难度与 IRT 校准参数分开；首版不提供未经校准的 IRT 估计。

后续新增字段优先兼容；删除字段或改变语义必须升级版本并同步更新示例与验收。
