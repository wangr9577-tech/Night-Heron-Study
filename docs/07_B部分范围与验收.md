# B1–B8 实现范围与本地验收边界

依据分工方案及当前仓库整理。下表区分已实现的接口和已实际运行的测试；“本地实现”不等于远程模型、正式部署或真实设备已经验收。测试命令和记录见 [本地测试报告](04_本地测试报告.md)。

| 部分 | 当前能力 | 主要证据与边界 |
| --- | --- | --- |
| B1 资料 | PDF、PPT/PPTX、图片和文本解析，OCR、来源片段、任务重试；Flutter 上传后先校对再确认提取 | `backend/materials/`、`tests/test_review_fixes.py`；复杂表格和扫描识别仍须对照原文人工校对。旧版 PPT 依赖外部转换器 |
| B2 图谱 | 知识点、来源、前置/相关关系及环检查；Flutter 可查看、编辑自己的知识点与关系 | `backend/knowledge/`、`tests/test_boundaries.py`、`app/test/graph_pages_test.dart`；自动提取基于标题、定义与显式关系规则，不能保证完整语义图谱 |
| B3 问答 | 基于课程资料检索、引用、提示，服务端可选接入模型 | `backend/tutoring/`、`tests/test_model.py`；默认无外部模型时是原文摘录和规则提示，模型配置及生成质量未在此证明 |
| B4 讲解 | 同一页面数据驱动文字、分段朗读、高亮和 PPTX；记录阅读位置 | `backend/lessons/`、`tests/test_lesson_readability.py`；正文主要依据原文切片，个别来源不足以出题时显示提醒，不能当作通用生成式讲解 |
| B5 模考 | 原卷编号与知识点匹配草稿、可编辑蓝图、生成试卷及答案 PDF | `backend/exams/`、`tests/test_flow.py`、`app/test/widget_test.dart`；原卷识别需用户确认，数值题仅支持已验证的有限题型，不能保证识别任意试卷或生成任意学科题目 |
| B6 错题 | 保留原题和原答、转写、独立审核、生成变式及分步讲解 | `backend/mistakes/`、`backend/tests/test_review_permissions.py`；审核须独立课程成员及服务端授权；变式按知识点模板生成，不保证与所有原题的解法结构完全等价 |
| B7 判题与掌握 | 练习、试卷和变式统一作答，提示/答案暴露影响证据，简答题需独立审核 | `backend/assessment/`；幂等、权限和证据测试见 `tests/` 与 `backend/tests/`。难度尚未经过 IRT 校准；自编题不产生出题者自己的掌握证据或积分 |
| B8 复习与事件 | SM-2 复习、到期建议、学习快照和用户范围事件；A 端事务消费与奖励去重 | `backend/review/`、`tests/test_algorithms.py`、`backend/tests/test_integration_real.py`；设备系统通知与真实时间下后台提醒尚需单独验证 |

本地演示验证不替代与合作方正式身份系统、生产部署、真实终端权限和外部服务的联调。OCR 校对、蓝图确认、课程审核和有无外部模型均应在演示时按实际状态说明。历史记录不会因修改本版规则自动回算。
