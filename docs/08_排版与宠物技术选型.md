# Flutter 排版与迷你宠物的开源参考

检索日期：2026-11-08。以下作为技术选型参考；除非依赖清单另有记录，本项目没有复制这些仓库的代码或素材。

| 项目 | 许可 | 可参考之处与当前取舍 |
| --- | --- | --- |
| [Flutter Markdown Plus](https://github.com/foresightmobile/flutter_markdown_plus) | BSD-3-Clause | 原生 Flutter Markdown 呈现。当前 OCR 和题面是普通文本，不应未经确认就解释成 Markdown；暂不引入。 |
| [Flutter Math](https://github.com/simpleclub/flutter_math) | Apache-2.0 | Flutter 数学公式渲染。只有明确为 TeX 的内容才可采用；当前资料提取不保证产生有效 TeX，暂不引入。 |
| [思源黑体](https://github.com/adobe-fonts/source-han-sans) | [SIL OFL](https://github.com/adobe-fonts/source-han-sans/blob/master/LICENSE.txt) | 中文字体可离线分发，但完整字体体积较大；当前先使用设备字体并保持系统字号缩放。若未来打包字体须随包保留许可。 |
| [Flame](https://github.com/flame-engine/flame) | MIT | Flutter 2D 游戏框架，支持精灵图和动画；适合未来扩展复杂场景。当前伙伴动画规模较小，先用 Flutter 自带绘制与动画。 |
| [Agent Pet](https://github.com/xiangking/agent-pet) | MIT | 可参考其 Codex 兼容帧图集和状态切换设计；该仓库是桌面应用，不能直接当作 Flutter Android 组件。仓库中素材的具体许可需单独核对。 |

阅读界面使用 Flutter 原生排版并尊重系统无障碍字号；源码文字与公式不因排版被重写。自动生成题目按原文片段提取、每题遮盖一次；来源表格仍需人工核对。迷你宠物支持内置形象和可选图集；图像服务没有配置时不声称已接入 AI 制图。
