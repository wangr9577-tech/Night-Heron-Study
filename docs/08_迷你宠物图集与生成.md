# 迷你宠物素材与可选生成服务

伙伴有内置动态形象；用户可以为自己的伙伴上传或删除自定义精灵图。服务端按账号和伙伴验证所有权，图集存储在应用 SQLite 数据库中。未上传时使用内置形象；上传成功后不会修改伙伴名字、积分和成长记录。

## 图集格式

使用静态 PNG 或 WebP，大小不超过 8 MiB，尺寸必须是 **1536×1872** 或 **1536×2288**。画布为 8 列、每格 192×208 像素；前 9 行依次为待机、向右跑、向左跑、挥手、跳跃、失败、等待、运行、审核，每行使用帧数为 6、8、8、4、5、8、6、6、6。1536×2288 中额外两行目前不使用。图片应包含透明背景及对齐良好的角色，否则实际播放效果由图集本身决定。服务端只验证格式、尺寸和可解码，不证明动作连续或角色一致。

## 接口

以下接口均需 Bearer 登录，路径前缀是 `/api/v1`：

- `GET /companion/sprite-capabilities`：返回尺寸、大小和 `generation_configured`；它表示配置存在，不保证上游服务可用。
- `PUT /companion/pets/{pet_id}/sprite`：multipart 上传字段 `file`，返回 `pet_id`、`mime`、`sha256`、`updated_at`；校验失败时旧图集保持不变。
- `GET /companion/pets/{pet_id}/sprite`：返回实际 PNG/WebP，未上传或无权访问为 404。
- `DELETE /companion/pets/{pet_id}/sprite`：删除自定义图集，重复删除可安全执行；客户端应回退内置形象。
- `POST /companion/pets/{pet_id}/sprite/generate`：请求 `{"description":"形象描述"}`；成功时在上述元数据中附带 `generated: true`，然后使用 GET 读取。未配置生成服务时返回 503，失败或生成内容不符合格式时不会覆盖旧图集；生成过程中已有图集被修改时返回 409，不覆盖新图集。

## 配置图像生成适配器

现有文字问答模型不代表能输出有效精灵图。若要在应用内生成，管理员需配置自己信任的图集生成服务：`ZHI_PET_SPRITE_URL` 为其完整 POST 地址，可选 `ZHI_PET_SPRITE_API_KEY` 从服务端以 Bearer 方式发送。**不要将密钥写入客户端或仓库**；客户端只能提供形象描述，不能指定请求 URL。

适配器收到的 JSON：

```json
{"description":"一只戴蓝围巾的夜鹭", "format":"codex-sprite-sheet-v1", "columns":8, "rows":9, "tile_width":192, "tile_height":208}
```

适配器返回 HTTP 200 和 `{"image_base64":"<标准 Base64 编码的完整 PNG 或 WebP 文件>"}`。它应自行调用实际图像模型、制作和校对满足上述格式的完整图集；此接口不是任意模型的原生 API。图像模型可能生成不对齐或动作不一致的图，必须由适配器或人工校验。服务端会验证内容并限制响应大小，不会将服务端密钥返回给客户端。仓库仅用 MockTransport 测试本合同，没有声称实际第三方生成服务已配置或通过联调。
