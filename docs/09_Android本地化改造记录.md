# Android 本地版改造记录

目标是无账号在手机上保存课程和资料，按需配置模型服务；现有服务器版继续保留。不得把开发阶段的局部功能称为完整离线版，也不得清除演示数据以安装。

## 验收边界与后续工作

根据最新需求，手机保存资料和学习记录，出题、组卷等智能能力直接调用用户选择的 AI，不再以完整移植 B1–B8 离线引擎为目标。本机功能的最终安装包与演示已验收，见 [2026-11-10 验收报告](10_2026-11-10_本地AI组卷验收.md)；真实模型服务仍需使用用户自己的配置独立验证。服务器积分及历史账户数据不自动合并。本机体验尚无完整备份和恢复功能，卸载应用可能删除设备内数据；不得覆盖旧数据库或误报完成。

## AI 组卷与本机数据（2026-11-10）

本机模式不要求运行自建后端：课程资料、题目、试卷和作答记录保存在设备上；AI 出题由用户配置的兼容 Chat Completions 接口提供。用户在试卷页选择一份资料并点击生成后，App 将该资料前 12000 个 Unicode 字符及命题要求发送给所配置的服务。API Key 存于设备安全存储；数据处理和费用由所选服务决定。

当前 AI 组卷支持 1–10 道简短答案题。模型须返回题目、参考答案、解析和资料原文引用；App 拒绝格式错误或无法在已发送资料中找到的引用。用户可以修改候选题，确认后才在同一个事务中保存题目与试卷。引用匹配不能保证题目和答案正确，必须人工核对；提交后的判分是文字匹配，等价答案可能被误判。手动选题功能保留。生成原卷分析、复杂题型、语义判分等尚不能以本路径宣称完成。

模型服务测试应区分：本地模拟 HTTP 服务可以验证请求格式、存储和错误处理，不能证明真实服务的密钥、配额、模型兼容性或生成质量。模型无法使用时，检查地址、模型名称、密钥、网络以及服务是否支持该接口。
